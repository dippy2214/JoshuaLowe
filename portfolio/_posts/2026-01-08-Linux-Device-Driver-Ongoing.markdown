This entry represents an ongoing project of mine to learn about linux device drivers and how they interact with the kernel. I have made good progress at the time of writing, learning about GPIO interrupts, sysfs and procfs, sending signals to user space etc. and I am really happy with this and enjoying the project a lot. The end goal is to make a device driver for the Wiimote to allow it to be recognised as a proper HID device via bluetooth, and a specific focus is being placed on learning a strong foundation first and properly understanding how linux device drivers interact with the operating system.

Paper notes have been a huge focus for me with this project, so I don't have so much to show digitally. Huge thanks for Johnnes for GNU/Linux for his incredible [youtube series](https://www.youtube.com/playlist?list=PLCGpd0Do5-I3b5TtyqeF1UdyD4C-S-dMa) going through device drivers on a raspberry pi, it is an incredible learning resource for anyone looking to get started with the topic.
